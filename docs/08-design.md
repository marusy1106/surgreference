# 8. Дизайн: направление и система

Визуальный язык, выведенный из присланных референсов. Этап 4 воплотил его в коде: токены и UI-кит — `mobile/lib/app/theme`, `mobile/lib/core/ui`, витрина — `mobile/widgetbook`, макеты — эталонные скриншоты в `mobile/test/**/goldens` (см. 8.5).

## 8.1. Что берём из референсов

| Референс | Приём | Как применяем в SurgReference |
|----------|-------|------------------------------|
| Финансовое приложение (тёмный онбординг, «сфера») | размытая градиентная «аура» на чёрном, тонкие линии-орбиты, кнопка-пилюля со стрелкой в круге | онбординг и главная: аура цвета текущей дисциплины; кнопки «Начать →», «Продолжить →» |
| Veri (глюкоза) | крупные карточки с мягким цветным свечением, точечные (dot-matrix) цифры, тонкие шкалы-линейки, жёлто-лаймовый маркер | показатели: XP, результат теста, серия дней, освоение; таймер и прогресс внутри теста |
| Aetna (медуслуги, светлый) | белые карточки с большим радиусом, синие акцентные карточки, круглые кнопки-стрелки, чипы-фильтры | **светлая тема**: каталог, списки, справочники |
| Activity / Expiratory Volume | карусель карточек с перспективой, плиточная сетка разных размеров, плашка действия внизу карточки | главная (карусель «Последний тест / Кейс дня»), экран теста (плашка «Ответить / Завершить») |

Итог: **тёмная тема — «аура»** (эмоциональная, для мотивации и практики), **светлая — «клиническая»** (чистая, для чтения уроков и справочников). Обе построены на одних токенах.

## 8.2. Токены

### Цвета

Вторая версия токенов (после сверки с референсами): цвет несут только «ауры» дисциплин; интерфейс вокруг них монохромный, лайм — крошечный маркер, а не заливка.

| Токен | Тёмная (Activity, Veri, финансовое приложение) | Светлая (Aetna) |
|-------|--------|---------|
| `bg` | `#060607` | `#EDEDEB` |
| `surface` | `#131315` | `#FFFFFF` (с рамкой `line`) |
| `surface-2` | `#1C1C1F` | `#F4F4F2` |
| `line` | `rgba(255,255,255,.10)` | `rgba(0,0,0,.12)` |
| `text` | `#F4F4F6` | `#0E0E10` |
| `text-muted` | `#9C9CA5` | `#5F5F66` |
| `accent` — выбранный чип, точка меню, круг кнопки | `#F4F4F6` (белый) | `#0E0E10` (чёрный) |
| `on-accent` | `#060607` | `#FFFFFF` |
| `marker` — бегунок шкалы, дуга прогресса, линия графика | `#D6F45B` (лайм) | `#4E6FD8` (синий Aetna) |
| `success` / `error` / `warning` | `#5BD69A` / `#FF6B6B` / `#FFB547` | `#13703F` / `#B82C2C` / `#985A00` |

Цвет никогда не единственный носитель смысла: верный/неверный ответ — ещё и иконка ✓/✕ и текст. Маркер — не текст: для него проверяется контраст 3:1 (WCAG 1.4.11).

### Ауры дисциплин

Карточка как в Activity и Veri: глубокая основа, мягкое радиальное свечение сверху слева, лёгкое зерно, цветной ореол снаружи; текст белый.

| Дисциплина | Свечение → основа |
|-----------|------|
| Хирургия | `#C8441B → #1F0905` |
| Терапия | `#C42A78 → #1D0614` |
| Кардиология | `#C42346 → #1C0510` |
| Неврология | `#5A43E0 → #0D0A2A` |
| Педиатрия | `#16806A → #03140F` |
| Фармакология | `#2F5BE0 → #060F2A` |

Новая дисциплина получает ауру из палитры в админке (`palette_token`); неизвестный приложению токен показывается аурой хирургии. Свечение подобрано так, что в самой яркой точке (85 % свечения поверх основы) белый текст и приглушённый белый (86 %) дают контраст ≥ 4,5 — это проверяет `test/app/contrast_test.dart`.

### Типографика, формы, движение

- Шрифт интерфейса — **Manrope** (полная кириллица, вариативный), размеры: 34 / 28 / 22 / 17 / 15 / 13. Заголовки — вес 500, не жирные: плотность даёт размер и чуть сжатый трекинг.
- Крупные числа (XP, балл, серия, таймер) — **точечный шрифт**: мелкие точки на редкой сетке, незажжённые еле видны; для скринридера у виджета `Semantics(label: "Результат 8 из 10")`.
- Кнопка — пилюля со стрелкой в круге: в тёмной теме полупрозрачная с белым кругом, в светлой чёрная; вторичная — контурная.
- Нижнее меню — только иконки и точка под активной; подпись — в подсказке и для скринридера.
- Радиусы: карточки 32, плитки 26, кнопки и чипы — пилюля. Плитки и поля ввода — с тонкой рамкой.
- Отступы — сетка 4 pt (8 / 12 / 16 / 24 / 32).
- Онбординг: вытянутая «сфера» — тёплое ядро цвета дисциплины и синий край, тонкие орбиты.
- Движение: медленное «дыхание» ауры (8–12 с), переходы 200–300 мс; всё отключается при системной настройке «Уменьшение движения».

### Компоненты UI-кита

`AuraCard`, `Tile` (1×1, 2×1), `DotNumber`, `RulerScale` (шкала с маркером), `PillButton` (с круглой стрелкой справа), `IconCircleButton`, `SegmentedPill` (Неделя / Месяц / Год), `ChipFilter`, `AnswerOption` (состояния: обычный, выбран, верно, неверно, пропущен верный), `ProgressRing`, `StepIndicator` (точки), `EmptyState`, `Disclaimer`.

## 8.3. Ключевые экраны (эскиз композиции)

| Экран | Композиция |
|-------|-----------|
| Онбординг | чёрный фон, большая аура с орбитами, заголовок «Учись медицине. Шаг за шагом.», `PillButton` «Начать», дисклеймер мелко |
| Главная | «Привет, {никнейм}» + аватар; карусель `AuraCard`: «Последний тест 8/10» (DotNumber), «Кейс дня», «Продолжить урок»; сетка плиток: серия дней (DotNumber + линейка), XP за неделю, освоение, слабая тема |
| Каталог | светлая/тёмная сетка карточек дисциплин с аурой и % освоения; чипы «Все / Начатые / Освоенные»; поиск |
| Урок | чистая «клиническая» вёрстка, ширина строки ~65 знаков, блоки «Важно», таблицы с горизонтальным скроллом, внизу — источники, рецензент, дата, «Сообщить об ошибке», «Завершить урок» |
| Тест | индикатор шагов сверху, вопрос на крупной `AuraCard`, варианты — пилюли во всю ширину, плашка снизу «Ответить»; таймер — линейка (как в Veri) |
| Результат | DotNumber «8/10», XP-начисление, список вопросов с ✓/✕, раскрытие разбора по варианту |
| Кейс | шаги как карточки-«листы» (анамнез → осмотр → решение), выбор — пилюли; итог: путь пользователя vs оптимальный |
| Прогресс | `SegmentedPill` неделя/месяц/год, линейный график активности с маркером, столбцы освоения по дисциплинам (как экран Analytics в референсе) |
| Рейтинг | переключатель «Студенты / Вузы», «Мой вуз / Все», своё место закреплено снизу |
| Профиль | никнейм, уровень, образовательный статус отдельно, достижения, настройки |

## 8.4. Доступность

- Поддержка системного размера шрифта до 200 % без обрезания (адаптивные карточки, текст переносится).
- Контраст текста ≥ 4.5:1, крупного ≥ 3:1, в обеих темах; проверка в CI goldens + ручная.
- Размер тач-цели ≥ 44×44 pt.
- Semantics-метки у всех иконок, DotNumber, графиков (текстовое резюме графика).
- Полная работа с VoiceOver / TalkBack по ключевым сценариям.
- Тема: «Системная» по умолчанию, ручной выбор в настройках.

## 8.5. Что сделано на этапе 4

- **Токены уточнены тестом контраста** (`mobile/test/app/contrast_test.dart`): в светлой теме акцент и статусные цвета затемнены — прежние давали 2,9–4,4:1 на поверхностях и цветных подложках; текст на ауре стал тёмным (см. 8.2). Любая новая пара «текст/фон» добавляется в этот тест.
- **UI-кит** — все компоненты из 8.2 плюс `AuraBackground`, `ActivityChart`, `LabeledBar`, `InitialsAvatar` (аватар из буквы никнейма: фото не собираем), `SectionHeader`.
- **Экраны-макеты** (11): онбординг, код подтверждения, главная, каталог, урок, тест, результат с разбором, шаг кейса, прогресс, рейтинг, профиль. Экраны принимают готовые данные и ничего не загружают — на этапе 5 к ним подключаются провайдеры.
- **Доступность проверяется тестами**: на всех экранах при шрифте 200 % нет переполнений, тач-цели ≥ 44 pt, у кнопок есть подписи. Найдено и исправлено: переключатель периода рвал слова и был ниже 44 pt; точечные числа вылезали из плиток; подписи оси графика не помещались.
- **Решения по ходу**: точечные цифры — собственный рисунок 5×7, а не шрифт (нет лицензии и зависимости, стабильные эталоны); крупные числа растут со шрифтом не больше чем в 1,5 раза и ужимаются по ширине плитки, полное значение читает скринридер; подписи сегментов на крупном шрифте ужимаются, а не переносятся.
