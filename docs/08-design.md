# 8. Дизайн: направление и система

Подробные макеты — этап 4. Здесь — визуальный язык, выведенный из присланных референсов, чтобы архитектура UI-кита (`core/ui`) закладывалась сразу.

## 8.1. Что берём из референсов

| Референс | Приём | Как применяем в SurgReference |
|----------|-------|------------------------------|
| Финансовое приложение (тёмный онбординг, «сфера») | размытая градиентная «аура» на чёрном, тонкие линии-орбиты, кнопка-пилюля со стрелкой в круге | онбординг и главная: аура цвета текущей дисциплины; кнопки «Начать →», «Продолжить →» |
| Veri (глюкоза) | крупные карточки с мягким цветным свечением, точечные (dot-matrix) цифры, тонкие шкалы-линейки, жёлто-лаймовый маркер | показатели: XP, результат теста, серия дней, освоение; таймер и прогресс внутри теста |
| Aetna (медуслуги, светлый) | белые карточки с большим радиусом, синие акцентные карточки, круглые кнопки-стрелки, чипы-фильтры | **светлая тема**: каталог, списки, справочники |
| Activity / Expiratory Volume | карусель карточек с перспективой, плиточная сетка разных размеров, плашка действия внизу карточки | главная (карусель «Последний тест / Кейс дня»), экран теста (плашка «Ответить / Завершить») |

Итог: **тёмная тема — «аура»** (эмоциональная, для мотивации и практики), **светлая — «клиническая»** (чистая, для чтения уроков и справочников). Обе построены на одних токенах.

## 8.2. Токены

### Цвета

| Токен | Тёмная | Светлая |
|-------|--------|---------|
| `bg` | `#0B0B0D` | `#F3F3F1` |
| `surface` | `#151518` | `#FFFFFF` |
| `surface-2` | `#1E1E22` | `#ECECEA` |
| `line` | `rgba(255,255,255,.08)` | `rgba(0,0,0,.08)` |
| `text` | `#F4F4F6` | `#0E0E10` |
| `text-muted` | `#9C9CA5` | `#5F5F66` |
| `accent` | `#D6F45B` (лайм — маркеры, активные индикаторы) | `#4C74E6` |
| `on-accent` | `#0B0B0D` | `#FFFFFF` |
| `success` / `error` / `warning` | `#5BD69A` / `#FF6B6B` / `#FFB547` | `#1F9D61` / `#D93A3A` / `#B86E00` |

Цвет никогда не единственный носитель смысла: верный/неверный ответ — ещё и иконка ✓/✕ и текст.

### Ауры дисциплин (градиенты карточек)

| Дисциплина | Аура |
|-----------|------|
| Хирургия | коралл → персик `#FF5A36 → #FFB38A` |
| Терапия | малиновый → розовый `#E0357F → #F2B3D3` |
| Кардиология | красный → лиловый `#E63946 → #9B5DE5` |
| Неврология | индиго → сирень `#4D4DE8 → #A99BF5` |
| Педиатрия | мята → шалфей `#6CC4A1 → #CDE6D8` |
| Фармакология | синий → голубой `#2F5BEA → #8FB3FF` |

Новая дисциплина получает ауру из палитры в админке (`palette_token`). Текст на ауре кладётся на затемнённую зону карточки (scrim), контраст проверяется ≥ 4.5:1.

### Типографика, формы, движение

- Шрифт интерфейса — **Manrope** (полная кириллица, вариативный), размеры: 34 / 28 / 22 / 17 / 15 / 13.
- Крупные числа (XP, балл, серия, таймер) — **точечный шрифт** только для цифр; для скринридера у виджета `Semantics(label: "Результат 8 из 10")`.
- Радиусы: карточки 28, вложенные плитки 20, кнопки и чипы — пилюля.
- Отступы — сетка 4 pt (8 / 12 / 16 / 24 / 32).
- Движение: медленное «дыхание» ауры (8–12 с), переходы 200–300 мс; всё отключается при системной настройке «Уменьшение движения».

### Компоненты UI-кита

`AuraCard`, `Tile` (1×1, 2×1), `DotNumber`, `RulerScale` (шкала с маркером), `PillButton` (с круглой стрелкой справа), `IconCircleButton`, `SegmentedPill` (Неделя / Месяц / Год), `ChipFilter`, `AnswerOption` (состояния: обычный, выбран, верно, неверно, пропущен верный), `ProgressRing`, `StepIndicator` (точки), `EmptyState`, `Disclaimer`.

## 8.3. Ключевые экраны (эскиз композиции)

| Экран | Композиция |
|-------|-----------|
| Онбординг | чёрный фон, большая аура с орбитами, заголовок «Учись медицине. Шаг за шагом.», `PillButton` «Начать», дисклеймер мелко |
| Главная | «Привет, {никнейм}» + аватар; карусель `AuraCard`: «Последний тест 8/10» (DotNumber), «Кейс дня», «Продолжить урок»; сетка плиток: серия дней (DotNumber + линейка), XP за неделю, освоение, слабая тема |
| Каталог | светлая/тёмная сетка карточек дисциплин с аурой и % освоения; чипы «Все / Начатые / Освоенные»; поиск |
| Урок | чистая «клиническая» вёрстка, ширина строки ~65 знаков, блоки «Важно», таблицы с горизонтальным скроллом, внизу — источники, рецензент, дата, «Сообщить об ошибке», «Завершить урок» |
| Тест | индикатор шагов сверху, вопрос на крупной `AuraCard`, варианты — пилюли во всю ширину, плашка снизу «Ответить»; таймер — линейка (как в Veri) |
| Результат | DotNumber «8/10», XP-начисление, список вопросов с ✓/✕, раскрытие разбора по варианту |
| Кейс | шаги как карточки-«листы» (анамнез → осмотр → решение), выбор — пилюли; итог: путь пользователя vs оптимальный |
| Прогресс | `SegmentedPill` неделя/месяц/год, линейный график активности с маркером, столбцы освоения по дисциплинам (как экран Analytics в референсе) |
| Рейтинг | переключатель «Студенты / Вузы», «Мой вуз / Все», своё место закреплено снизу |
| Профиль | никнейм, уровень, образовательный статус отдельно, достижения, настройки |

## 8.4. Доступность

- Поддержка системного размера шрифта до 200 % без обрезания (адаптивные карточки, текст переносится).
- Контраст текста ≥ 4.5:1, крупного ≥ 3:1, в обеих темах; проверка в CI goldens + ручная.
- Размер тач-цели ≥ 44×44 pt.
- Semantics-метки у всех иконок, DotNumber, графиков (текстовое резюме графика).
- Полная работа с VoiceOver / TalkBack по ключевым сценариям.
- Тема: «Системная» по умолчанию, ручной выбор в настройках.
